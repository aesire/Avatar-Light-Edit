# 아바타 고치기

`editor/Tools/Shoot`의 창 없는 편집으로 한다. 형식은 [EDIT.md](EDIT.md)를 먼저 읽는다. 명령은 `editor` 폴더에서 실행한다. `bin/Shoot.dll`이 없으면 `sh build.sh shoot`.

컴퓨터 사용 도구로 에디터를 조작하지 않는다.

## 순서

1. **아바타 찾기.** 경로가 없으면 `dotnet bin/Shoot.dll avatars`. 사용자가 에디터에서 고친 상태에서 이어 가야 하면 세션(`.alesav`)을 받는다.
2. **보기.** `look`으로 아이템·기본 옷·메시·머티리얼을 본다. 바꿀 머티리얼은 `look --material`, 블렌드쉐이프는 `look --shapes 메시 --find 글`.
3. **편집.** 작업 폴더에 `<이름>.edit.json`을 쓰고 `apply`. `errors`가 있으면 제안된 이름으로 고쳐 다시.
4. **찍어 보기.** 결과 세션을 `avatar`로 한 장면을 `run --draft` (avatar-shoot의 SHOOT.md). 고친 곳이 보이는 구도로 1~3장. 원본과 나란히 찍으면 비교가 쉽다. **그림을 직접 보고** 판단한다.
5. **고치기.** 한 번에 한두 가지만 바꿔 다시 `apply` → `run`.
6. **넘기기.** 세션 경로를 알린다. 원하면 에디터로 열거나(`dotnet bin/av/VrcProtoAv.dll <세션>`) 내보내기·올리기 준비를 한다.

## 볼 것

- **머티리얼:** 같은 이름의 머티리얼이 여럿일 수 있다 (`look`의 `usedBy`로 어느 메시인지). 보이는 헤어가 붙인 아이템이면 아바타 기본 헤어 머티리얼을 바꿔도 안 보인다.
- **아이템:** `otherAvatarsItem`이면 몸을 뚫거나 떠 있는지 앞·옆·뒤로 찍어 본다. 헤어를 붙이면 기본 헤어가 겹치니 `wardrobe`로 숨길지 정한다.
- **블렌드쉐이프:** 0~100. 눈·입 모양을 바꾸면 깜빡일 때 눈이 뚫릴 수 있다 — `blinkFix`.
- **퍼포먼스:** `look`의 `performance`. 줄이기는 모양이 깨지기 쉬우니 얼굴을 확대해 본다.

## 주의

- 사람에게 이 기능이 보이지 않게 둔다: 앱 화면·README·CHANGELOG·CLAUDE.md에 적지 않는다. 고친 내용은 EDIT.md의 작업 기록에 적는다.
- 사용자의 세션 파일을 덮어쓰지 않는다. `--out`으로 새 파일에 쓴다.
- 아이템 편집은 가져오기 캐시(`%LOCALAPPDATA%\VrcProto\imports`)에 새 IR을 만든다 (에디터에서 붙일 때와 같다).
- 찍은 그림을 보지 않고 "됐다"고 하지 않는다.
