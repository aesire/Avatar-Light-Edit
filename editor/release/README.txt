Avatar Light Edit
=====================
(English: README.en.txt · 日本語: README.ja.txt)

Unity를 열지 않고 VRChat 아바타의 겉모습(머티리얼·색·블렌드쉐이프·의상·자세)을 미리 보고 고치는 Windows 프로그램입니다.
무료이고 소스가 공개된 프로그램입니다 (GPLv3). VRChat이나 Unity가 만들거나 승인한 도구가 아닙니다.


필요한 것
---------
· Windows 10/11 64비트, DirectX 11이 되는 그래픽카드
· .NET이나 Unity는 설치하지 않아도 켜지고 볼 수 있습니다 (.NET을 함께 넣었습니다)
· 있으면 더 되는 것
  - Unity 2022.3 (VRChat 지정 버전): VRChat에 올리기, Unity 프로젝트로 내보내기, 내 셰이더로 셰이더 팩 만들기
  - Microsoft Visual C++ 재배포 패키지(x64): 웹캠 표정. 없으면 웹캠 표정을 켤 때 설치 안내가 나옵니다
  - SteamVR: VR로 보기


설치와 첫 실행
--------------
1. zip을 풀 곳에 그대로 풉니다. 문서 폴더처럼 내 계정으로 쓸 수 있는 곳이 좋습니다.
   Program Files에 넣으면 업데이트가 복사하지 못합니다. 폴더 경로가 너무 길면 켜지지 않으니 안내가 뜨면 짧은 곳으로 옮겨 주세요.
2. ALEdit.exe를 실행합니다.
   서명하지 않은 프로그램이라 "Windows의 PC 보호" 창이 뜰 수 있습니다.
   "추가 정보" → "실행"을 누르면 됩니다. 받은 곳이 공식 릴리스 페이지인지 먼저 확인해 주세요.
3. Ctrl+I로 아바타 .unitypackage나 Unity 프로젝트의 프리팹을 가져옵니다.

지울 때는 폴더를 지우면 됩니다. 설정과 가져온 파일은 아래 폴더에 남으니 필요 없으면 함께 지웁니다.
  %APPDATA%\ALEdit       설정, 충돌 기록
  %LOCALAPPDATA%\ALEdit  가져온 아바타, 캐시, 올리기용 프로젝트


업데이트
--------
새 버전이 나오면 왼쪽 아래에 "업데이트"가 보입니다. 누르면 받아서 프로그램 폴더를 바꾸고 다시 켭니다.
설정과 작업 파일은 그대로입니다. 설정 › 업데이트에서 자동 확인을 끌 수 있습니다.


자주 묻는 것
------------
Q. 아바타 원본 파일이 바뀌나요?
A. 아닙니다. 원본은 읽기만 하고, 고친 값은 세션 파일과 %LOCALAPPDATA%\ALEdit에 따로 저장합니다.

Q. 줄무늬로 보이는 머티리얼이 있어요.
A. 프로그램에 없는 셰이더입니다. 값은 그대로 보존됩니다. Unity가 있으면 셰이더 팩을 만들어 볼 수 있습니다.
   lilToon·Poiyomi 무료판·MToon은 기본으로 들어 있습니다.

Q. VRChat에서 보이는 것과 완전히 같나요?
A. 가깝게 맞추지만 같지는 않습니다. PhysBone은 VRChat 문서를 바탕으로 만든 근사 시뮬레이션이고,
   애니메이터·FX는 재현하지 않습니다. 올리기 전 최종 확인은 VRChat에서 해 주세요.

Q. VRChat에 올릴 때 계정 정보를 이 프로그램에 넣나요?
A. 아닙니다. 로그인은 Unity의 VRChat SDK 창에서 직접 합니다. SDK도 이 프로그램에 들어 있지 않고,
   올릴 때 VRChat 공식 저장소에서 내 PC로 받습니다. VRChat 이용 약관과 아바타 원본의 라이선스는 직접 지켜 주세요.

Q. 켜지지 않거나 갑자기 꺼져요.
A. 아래 "문제 알리기"를 봐 주세요.


문제 알리기
-----------
설정(Ctrl+,) › 정보 › "문제 알리기"의 폴더 열기를 누르면 충돌 기록(crash-날짜.txt)이 있습니다.
릴리스 페이지의 Issues에 무엇을 하다 그랬는지와 함께 최근 기록 파일을 붙여 주세요.
기록에는 아바타 이름과 PC 경로(사용자 이름 포함)가 적혀 있을 수 있으니, 올리기 전에 읽어 보고 가려도 됩니다.
기록을 저절로 보내는 기능은 없습니다.


개인정보
--------
이 프로그램은 사용 기록이나 아바타 파일을 어디로도 보내지 않습니다. 인터넷을 쓰는 곳은 다음뿐입니다.
· 업데이트 확인: 켤 때 GitHub에 최신 버전을 묻습니다 (설정에서 끌 수 있음)
· 구글 번역: 내가 API 키를 넣고 블렌드쉐이프 페이지에서 "구글 번역"을 켰을 때만 쉐이프키 이름이 Google Cloud로 갑니다.
  요금과 약관은 내 Google 계정 기준입니다
· VRChat 올리기 준비: VRChat SDK와 고른 기믹을 각 공식 저장소에서 받습니다
웹캠과 마이크(표정·입 모양)는 이 PC 안에서만 처리하며 저장하거나 보내지 않습니다.
VMC·OSC로 표정을 보내는 외부 프로그램을 연결하면 그 프로그램의 정책을 따릅니다.
