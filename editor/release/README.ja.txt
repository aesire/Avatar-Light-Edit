Avatar Light Edit
=====================
(한국어: README.txt · English: README.en.txt)

Unityを開かずに、VRChatアバターの見た目(マテリアル・色・シェイプキー・衣装・ポーズ)を確認して改変できるWindowsツールです。
無料でソースコードを公開しています (GPLv3)。VRChatやUnityが制作・承認したツールではありません。


必要なもの
----------
・Windows 10/11 64bit、DirectX 11 対応のグラフィックボード
・.NETやUnityをインストールしなくても起動して表示できます (.NETは同梱しています)
・あるとできること
  - Unity 2022.3 (VRChat指定バージョン): VRChatへのアップロード、Unityプロジェクトへの書き出し、手持ちのシェーダーでシェーダーパックを作る
  - Microsoft Visual C++ 再頒布可能パッケージ (x64): Webカメラでの表情。ない場合は、Webカメラの表情をオンにしたときにインストールの案内が出ます
  - SteamVR: VRで見る


インストールと初回起動
----------------------
1. zipを好きな場所にそのまま展開します。ドキュメントフォルダーのように、自分のアカウントで書き込める場所がおすすめです。
   Program Files に置くとアップデートがファイルをコピーできません。フォルダーのパスが長すぎると起動しないので、案内が出たら短い場所に移してください。
2. ALEdit.exe を実行します。
   署名のないプログラムのため「WindowsによってPCが保護されました」という画面が出ることがあります。
   「詳細情報」→「実行」を押してください。その前に、公式のリリースページから入手したものか確認してください。
3. Ctrl+I でアバターの .unitypackage や Unityプロジェクトのプレハブを読み込みます。
   表示言語は設定 (Ctrl+,) で変更できます: 한국어 / English / 日本語。

アンインストールはフォルダーを削除するだけです。設定と読み込んだファイルは下のフォルダーに残るので、不要なら一緒に削除してください。
  %APPDATA%\ALEdit       設定、クラッシュ記録
  %LOCALAPPDATA%\ALEdit  読み込んだアバター、キャッシュ、アップロード用プロジェクト


アップデート
------------
新しいバージョンが出ると、左下に「アップデート」が表示されます。押すとダウンロードしてプログラムのフォルダーを入れ替え、再起動します。
設定と作業ファイルはそのままです。設定 › アップデート で自動確認をオフにできます。


よくある質問
------------
Q. アバターの元ファイルは変更されますか?
A. いいえ。元ファイルは読み込むだけで、変更した値はセッションファイルと %LOCALAPPDATA%\ALEdit に別に保存します。

Q. 縞模様で表示されるマテリアルがあります。
A. このプログラムに入っていないシェーダーです。値はそのまま保持されます。Unityがあればシェーダーパックを作って表示できます。
   lilToon・Poiyomi(無料版)・MToon は最初から入っています。

Q. VRChatでの見え方と完全に同じですか?
A. 近づけていますが、同じではありません。PhysBoneはVRChatのドキュメントをもとに作った近似シミュレーションで、
   アニメーター・FXは再現しません。アップロード前の最終確認はVRChatで行ってください。

Q. VRChatにアップロードするとき、アカウント情報をこのプログラムに入力しますか?
A. いいえ。ログインはUnityのVRChat SDKウィンドウでご自身で行います。SDKもこのプログラムには入っておらず、
   アップロード時にVRChat公式リポジトリからご自身のPCにダウンロードされます。VRChatの利用規約とアバター元データのライセンスはご自身でお守りください。

Q. 起動しない、または突然終了します。
A. 下の「問題の報告」をご覧ください。


問題の報告
----------
設定 (Ctrl+,) › 情報 ›「問題を報告」のフォルダーを開くと、クラッシュ記録 (crash-日付.txt) があります。
リリースページの Issues に、何をしていたときに起きたかと一緒に、最新の記録ファイルを添付してください。
記録にはアバター名やPCのパス(ユーザー名を含む)が書かれていることがあるので、投稿前に読んで、隠したい部分は隠してかまいません。
記録を自動で送信する機能はありません。


プライバシー
------------
このプログラムは、使用履歴やアバターのファイルをどこにも送信しません。インターネットを使うのは次の場合だけです。
・アップデートの確認: 起動時にGitHubへ最新バージョンを問い合わせます (設定でオフにできます)
・Google翻訳: ご自身でAPIキーを入力し、ブレンドシェイプのページで「Google翻訳」をオンにしたときだけ、シェイプキーの名前がGoogle Cloudに送られます。
  料金と規約はご自身のGoogleアカウントに従います
・VRChatアップロードの準備: VRChat SDKと選んだギミックをそれぞれの公式リポジトリからダウンロードします
Webカメラとマイク(表情・口の動き)はこのPCの中だけで処理し、保存も送信もしません。
VMC・OSCで表情を送る外部プログラムをつないだ場合は、そのプログラムのポリシーに従います。
