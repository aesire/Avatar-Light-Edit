# Avatar Light Edit (ALEdit) — 자동화 안내

사용자가 AI에게 아바타 사진·영상·스티커·포즈·조명 작업을 부탁했을 때 읽는 문서다. 창을 조작하지 않고 이 폴더의 `Shoot.exe`로 한다. 명령과 장면 파일 형식은 [SHOOT.md](SHOOT.md)에 있다.

- 답은 사용자의 말로 한다.
- `Shoot.exe`는 이 폴더에서 실행한다. 답은 JSON이다. 찍은 파일 경로가 답에 들어 있다.
- 처음 실행에 렌더러를 띄운다 (창 없음). 20분 쉬면 저절로 끝난다.

## 순서

1. **아바타 찾기.** `Shoot.exe avatars`는 가져온 아바타 목록을 보여 준다. 사용자가 고친 상태를 찍으려면 사용자가 저장한 세션(`.alesav`)을 쓴다. 어느 아바타인지 애매할 때만 묻는다. 아직 가져온 적이 없으면 `Shoot.exe import <패키지·프리팹·FBX>`.
2. **아바타 보기.** `Shoot.exe inspect <아바타>`로 표정·렌더러·뼈를 본다. 블렌드쉐이프는 `--shapes 찾을글`, 머슬 이름은 `--muscles`.
3. **기획.** 용도·비율·분위기를 정하고 샷을 나눈다. 사용자가 세세히 정하지 않았으면 직접 정해 장면의 `brief`에 적는다. 참고 그림을 받았으면 포즈·구도·표정·조명·배경으로 나눠 맞춘다.
4. **장면 쓰기.** 사용자의 작업 폴더에 `<이름>.scene.json`으로.
5. **시안.** `Shoot.exe run <장면> --draft`. `errors`가 있으면 제안된 이름으로 고친다. `sheet`(한 장이면 그 사진)를 **직접 열어 본다**. 이미지를 볼 수 없는 환경이면 사용자에게 보여 주고 고칠 점을 묻는다.
6. **고치기.** 장면만 고쳐 다시 `--draft`. `--only 장이름`이면 빠르다. 한 번에 한두 가지만 바꾼다.
7. **완성본.** `Shoot.exe run <장면> --only 장이름`. 파일 경로를 사용자에게 알린다.
8. **에디터로 넘기기.** 사용자가 이어서 고치고 싶어 하면 `Shoot.exe edit <장면> --only 장이름`. 배경 등 스튜디오 값은 그 PC의 에디터 설정으로 남는다고 먼저 말한다.

## 볼 것

- **포즈:** 관절이 꺾이면 안 되는 쪽으로 꺾이지 않았는가, 손이 몸·옷·머리를 뚫지 않는가, 발이 바닥에 닿는가, 몸이 떠 있지 않은가. 머슬 값은 체형마다 결과가 다르니 시안으로 확인한다. 방향이 헷갈리면 값 하나씩 시험하는 장을 찍는다.
- **표정:** 눈이 뚫리거나 입이 찢어지지 않는가. 아바타 기본 표정 이름부터 쓴다.
- **구도:** 머리 위·손끝이 잘리지 않는가, 관절에서 자르지 않는가. 인물은 `fov` 20~30, `angle` ±15~30이 입체적이다.
- **조명:** 툰 셰이더는 빛이 세면 금방 하얗게 뜬다. 얼굴이 날아가면 `front`·`intensity`·`ambient`를 낮춘다.
- **배경:** 인물과 색이 겹치면 윤곽이 묻힌다. 바닥색은 조명을 받아 적은 색과 달라 보인다.
- **후처리:** `post`를 적으면 블룸이 0.6으로 켜진다. 원치 않으면 `"bloom": 0`.

## 주의

- 찍은 그림을 보지 않고 "됐다"고 하지 않는다. 사용자가 한 말과 다르게 찍은 것(숨긴 파츠, 바꾼 각도)은 알린다.
- 앉은 포즈는 치마 속이 보이지 않는 각도로 찍는다. 성적인 촬영은 하지 않는다.
- 웹캠·마이크는 사용자가 원할 때만 켠다. `overlay on`은 사용자 화면(방송 중일 수 있다)에 바로 보이므로 부탁받았을 때만, 다 쓰면 `overlay off`.
- 남의 아바타·그림을 쓸 때의 권리는 사용자에게 달렸다. 재배포 금지 데이터(아바타 원본·텍스처)를 밖으로 보내지 않는다.
